# SPARK × Among Us IRL

Static landing page + registration for the SPARK (IIIT Bhopal) real-life Among Us event.

- `index.html` markup, `css/style.css` styling, `js/script.js` interactions
- Edit the `EVENT` block at the top of `js/script.js`: date, venue, `confirmed`, and `endpoint` (a form/sheet URL that accepts a JSON POST).
- Schedule times and FAQ answers in `index.html` are placeholders until organisers confirm them.
- No secrets, no build step. Run by opening `index.html`, or deploy the folder to Vercel/GitHub Pages as a static site.
